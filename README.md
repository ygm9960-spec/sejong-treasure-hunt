# 학생자치회 보물찾기 v3.0 · 시네마틱 UI 리뉴얼

## 적용 방법
1. `index.html` 파일만 기존 GitHub 저장소 `ygm9960-spec/sejong-treasure-hunt`의 루트 `index.html`과 교체합니다.
2. `Commit changes`로 저장합니다.
3. 기존 웹앱 주소를 새로고침합니다. 캐시가 남으면 Ctrl+Shift+R로 새로고침하세요.

**기존 `firebase-config.js` 파일은 삭제하거나 수정하지 마세요.** QR 80개와 보물 12종을 다시 생성하거나 Firebase 참가 기록을 초기화할 필요도 없습니다.

## 이번 버전의 개선 사항
1. 황금빛/보라색 마법진과 보물 카드 공개를 결합한 1~2초 내외 시네마틱 연출. 최초 발견은 전용 효과, 건너뛰기 제공.
2. 기존 10종 꽝의 테마별 미니 애니메이션(오류/조롱/허무/낚시 등).
3. 획득·미발견·최초 발견 도감 카드에 서로 다른 홀로그램/터치 반응.
4. 보물 수집량 0~2, 3~5, 6~8, 9~11, 12개에 따라 변하는 메인 보물상자.
5. 3·6·9·12개 수집 달성 시 칭호 강조 효과.
6. 황금색 QR 인식 프레임과 카메라 오류 시 다시 실행 버튼.
7. 기본 음소거 유지, 사용자가 활성화할 때만 버튼·스캔·보물·꽝·최초 발견 효과음 재생.
8. 화면·모달 전환을 부드럽게 조정, 모션 줄이기 환경설정 지원.

## 유의사항
- 기존 임원/보물 이미지 파일을 생성하거나 교체하지 않았습니다. 기존 등록 이미지는 계속 사용하며 신규 이미지에도 같은 효과가 적용됩니다.
- 힌트·위치 기록·상품 지급 관리·타이머·빠른 모드는 추가하지 않았습니다.
- 로컬 브라우저 테스트: 학생 등록, QR 수동 입력, 보물 최초 발견, 꽝, 카드 상세, 스캐너 오류 UI 확인.
- 실제 Firebase 다중 사용자 및 기기 카메라 동작은 이 파일 배포 후 실기기로 최종 확인해 주세요.
- 이번 버전은 화면 표현과 효과 위주의 수정으로 Firebase 컬렉션/규칙을 변경하지 않았습니다.
